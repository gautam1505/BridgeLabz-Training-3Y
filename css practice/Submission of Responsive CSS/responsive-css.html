Q6. Responsive CSS Cheat Sheet

Filters

CSS filters modify the appearance of images.

filter: grayscale(100%);

Media Queries

Used to apply CSS depending on screen size.

@media (max-width: 700px)

Responsive Design

Makes websites work on different screen sizes.

width: 100%;

Typography

Text can scale using relative units and clamp().

font-size: clamp(1rem, 2vw, 2rem);

Flexbox

Flexbox creates flexible layouts.

display: flex;

CSS Grid

Grid creates rows and columns.

display: grid;

Q9. Responsive Design Principles

Fluid Layouts

Layouts use flexible units so content adjusts to different screen sizes. 

width: 100%;
max-width: 1200px;

Flexible Media

Images and media should resize inside their containers. 

img {
    max-width: 100%;
    height: auto;
}

Breakpoints

Media queries change the layout at different screen sizes. 

@media (max-width: 600px) {
    ...
}
